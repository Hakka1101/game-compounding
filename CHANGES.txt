── 何が起きていたか ────────────────────────────
  Netlify の設定の問題ではなく、保存（localStorage）が実際に効く環境でだけ出るバグでした。

  explore.js の renderExplore() は、外に出ているあいだ（phase === 'out'）
  調合所のタブを disabled にし、強制的に採取画面へ切り替えます。これは仕様どおりです。

      const craftTab = document.querySelector('.view-tab[data-view="craft"]');
      if (craftTab) craftTab.disabled = (ph === 'out');
      if (ph === 'out') showView('explore');

  ところが保存の呼び分けがずれていました。

      searchCell()  … マスを調べるたびに保存する → phase: 'out' が書かれる
      goHome()      … 帰宅しても保存しない      → 'out' のまま残る

  つまり一度でも採取に出てマスを調べると、保存には「外にいる」と書かれます。
  工房へ戻っても、翌日へ進むまでその事実は書き込まれません。
  その状態でページを閉じる／再読み込みすると、毎回「外にいる」状態で復元され、
  調合所のタブが押せないまま採取画面だけが出ます。

── なぜローカルでは起きなかったか ─────────────────
  index.html を file:// で直接開くと、多くのブラウザは null オリジンの localStorage を
  遮断します。progress.js の loadGame() は try/catch で握りつぶすので、
  読み込み失敗＝毎回まっさらな状態＝ phase は必ず 'before' になり、調合所が普通に開きます。
  Netlify は本物の https オリジンなので保存が効き、上の状態が固定されます。

── 直したところ ───────────────────────────────
  explore.js
    ・goHome() に saveGame() を追加（帰宅を書き残す。これが本体）
    ・enterArea() / chooseTimeSlot() にも saveGame() を追加し、
      場面が変わったら必ず保存が追いつくようにした
  progress.js
    ・restore() に保険を追加。'out' で保存されていても、
        時間帯が決まっていない → 'before'
        ターンが尽きている     → 'after'
      として読み直す。壊れた保存でも調合所に入れなくなることがない。

── いま上がっているサイトの直し方 ───────────────────
  差し替えて上げ直せば、次の1回だけ「工房へ戻る」を押してください（そこで保存されます）。
  それでも直らない場合は、ブラウザの開発者ツール →
  Application → Local Storage → chougoujo.save.v1 を削除すれば最初から始まります。

── もう一点、確認をお願いしたいこと ──────────────────
  いただいたフォルダに data_effects.js が入っていませんでした。
  index.html はこれを読み込むので、アップロード漏れやファイル名の大文字小文字違いがあると、
  Netlify（Linux・大文字小文字を区別する）では 404 になります。
  Windows や macOS のローカルでは区別しないため、そこでだけ動く、という状態になります。
  画面上部に赤い「起動できませんでした」の帯が出ていたら、これが原因です。

── 動作確認 ────────────────────────────────
  node test_resume.js  … 保存の読み直し11項目（すべて通過）
    ・採取中に閉じた保存は、採取中のまま続きから遊べる
    ・「工房へ戻る」でタブが開き、その帰宅が保存に書かれる
    ・帰宅後の保存を読み直しても調合所が開く
    ・外にいるのにターンが尽きている保存からも復帰できる
  node test_vessel.js / node test_progress.js も引き続き通過。

── 直した理由 ────────────────────────────────
  紙片が素材を名指ししないのは全117枚に共通の書き方で、「曖昧」タグとは無関係だった。
  最初から持っている28枚は、確か・曖昧の別なく全部が言い換えで書かれている。
  言い換えの相手は素材の説明文（例：紙片「大地の血のような水」／
  鉄渋の湧き水「大地の血が混じったような重く渋い水」）なので、
  素材の一覧を引ければ解ける。しかしその一覧が引けなかった。

      main.js visibleItems():  if (held(it.id) <= 0) return false;

  everHeld（一度でも手にしたか）は記録されていたが、表示には使われていなかった。
  「曖昧」タグは reliability の表示にしか使われておらず、判定には一切関わらないので、
  そのまま残した。

── 直したところ ───────────────────────────────
  main.js
    ・visibleItems()：採取素材71種は所持数0でも常に棚へ並べる。
      調合品115種は一度その手で作るまで伏せる。瓶2種は従来どおり棚に出さない。
    ・handleItemClick()：手元に無いものを押しても覚え書きだけは開くようにした
      （従来は早期 return で描画ごと飛んでいた）。調合台には載らない。
    ・renderItemMemo()：未入手と入手済みで出し分ける。
        未入手  … 説明文（1行）＋ エリア名。地形と時間帯は伏せる。
        入手済み… 祖母の書き付け（詳細）＋ 説明文 ＋ 地形・時間帯・備考。
    ・素材ごとの採取行とエリアの索引を追加（spawnsByItem / areasByItem）。
  style.css
    ・.item-entry.unheld（薄く表示）と .memo-body.memo-unknown（斜体）を追加。

── エリア名の出し方について ─────────────────────
  草むらのようにどの土地にもある地形の素材は、9エリアに散ります。
  71種を数えたところ、45種は1〜2エリアに絞れますが、16種は5〜9エリアに広がっていました。
  全部並べると手がかりにならないので、出現確率の合計が高い順に3つまでとしています。

      イバラアザミ  → 「草原・森・荒野あたりのどこかにあるという。」
      鉄渋の湧き水  → 「高原・洞窟のどこかにあるという。」
      地熱帯の硫黄水 → 「火山帯のどこかにあるという。」

  上限を変えたい場合は renderItemMemo() の areas.slice(0, 3) の数字だけ直してください。

追加で差し替えるファイル
  data_recipes.js  game_data_v26.xlsx（Recipes シート）

── 理由 ────────────────────────────────────
  蒸留水は categoryId が processed なので、categoryId=liquid の条件には決して当てはまらない。
  つまり「水質そのまま」を要求するレシピは、汲んだ生水しか受け付けていなかった。
  最初の紙片で祖母がこう言っているのに、である。

      「これをやらずに薬を作る奴は、泥水で顔を洗うようなものだ」

  実際、変更前は野草の傷薬に「雨溜まりの泥水」がそのまま使えた。

  さらに、蒸留水の書き方が2通りに割れていた。

      消毒液      itemId=item_059 / そのまま     紙片「蒸留水で薄める」
      傷口洗浄液  categoryId=liquid / 蒸留       紙片「蒸留した水で割る」

  同じ言い回しの紙片なのに手順が違うので、片方を覚えるともう片方で必ず失敗する。

── 変更したレシピ（5本） ─────────────────────────
  用途が「消耗品」＝飲む・塗る薬の溶媒を、蒸留水に付け替えた。

      加速の秘薬     liquid/煮る       → item_059(蒸留水)/煮る
      野草の傷薬     liquid/そのまま   → item_059/そのまま
      鎮静の丸薬     liquid/そのまま   → item_059/そのまま
      解熱の煎じ薬   liquid/そのまま   → item_059/そのまま
      傷口洗浄液     liquid/蒸留       → item_059/そのまま   ※書き方の統一

  紙片の文面はどれも「水でのばす」「煮た水に溶かす」のままで矛盾しないので、
  RecipeHints は触っていない。

── 変更していないレシピ（5本） ───────────────────
  中間素材は汲んだ水のまま残した。採取した水質13種の使い道がここに残る。

      蒸留水（liquid/蒸留）　凝固薬（liquid/煮る）　冷却晶（liquid/そのまま）
      灰汁液（liquid/煮る）　獣脂（liquid/そのまま）

  結果として、紙片の一枚目が教えている規則がそのまま遊びの規則になる。

      中間素材を作る  → 汲んだ水でよい
      飲む・塗る薬    → 必ず蒸留水を通す

  「水」と書いてあれば蒸留水のこと、と読めるようになるので、
  紙片全体の曖昧さはむしろ減る。

    「蒸留水を作る→薬にする」で消費は従来どおり1本
  ・野草の傷薬と鎮静の丸薬は最初から持っている紙片だが、
    蒸留水の紙片も「最初から・確か」なので、詰まりは増えない
  node test_solvent.js … 11項目（すべて通過）
    ・汲んだ水では傷薬にならない／蒸留水なら通る
