調合所　― ファイル一式

【遊び方】
index.html をブラウザで開くだけです。
すべてのファイルを同じフォルダに置いたままにしてください。
一つでも欠けると、起動時に画面へその旨が表示されます。

【始め方】
開くと表題が出ます。続きがあれば「続きから」、無ければ「始める」。
「始める」を選ぶと、開幕の文が五枚。読み飛ばせます。
続きがある状態で「最初から始める」を押すと、確認のうえで記録を捨てて一日目に戻ります。

【続きから遊ぶ】
進行は自動でブラウザに保存されます。表題で「続きから」を選べば続きです。
足元の「保存」を押すと、持ち運べる文字列が出ます。控えておけば別の環境でも再開できます。
再開するときは同じ「保存」を押し、受け取った文字列を貼り付けて OK。

【一年で返すもの】
  祖母の療養で作った借財 8,000 を、一周忌の朝（160日目）までに手元へ用意します。
  足りなければ、ほかに何をしていても店と家を渡す結末になります。
  額と開幕の文は opening.js の OPENING_DATA にあります（xlsx からは作っていません）。

【一年の流れ】
  1年160日（1週5日 / 1月20日 / 8ヶ月）。満月は月の10日目。
  一日にできることは、採取に出るか、休んで日を送るか。
  採取は時間帯を一つ選び、10ターン。工房から出るのは無料、場所を移ると1ターン。
  売り買いにターンは要りません。ただし外にいる間は店を開けられません。
  160日目に、その一年ぶんの結末が出ます。

【中身】
  index.html / style.css
  main.js      調合・覚え書き・画面制御
  explore.js   採取
  calendar.js  暦と月齢
  progress.js  記録・旗・出来事・結末・保存
  opening.js   表題・開幕の文・最初から始める・借財
  shop.js      店・行商人・夜の客
  data_*.js    データ（xlsx から自動生成）
  game_data_v25.xlsx  元データ。編集はここで行う
  tools/convert.py    xlsx から data_*.js を作り直す
  tools/test_*.js     動作確認用（node と jsdom が要る）

【データを直したら】
  python3 tools/convert.py game_data_v25.xlsx .
