■ 1. 季節しばりを外した

  calendar.js
    conditionsOf() が季節を返さないようにした。
    採取を左右するのは エリア・地形・時間帯・満月 の四つだけになる。
    date.season は暦の表示用にそのまま残してある。

  data_spawns.js
    「雪解けの走り水」の 春 限定だった 2行（夜明け 0.50 / 朝 0.38）から
    条件を外した。これで六つの時間帯すべて、一年中とれる。
    満月しばりは残した（ホウオウノハネ／噴気孔／深夜 0.12）。
    → 満月は 20日に一度、160日で 8日。

  ※ 名前について
    「雪解けの走り水」は一年中とれるようになったので、名前と
    書き付けが季節を指したままです。気になるようなら改名を。


■ 2. 「風上で使うな」を揮発に直した

  data_recipes.js
    獣香の誘引剤 の二番目の材料
      reactionId: permeate（浸透）→ volatile（揮発）
      note:「浸透素材で匂いを拡散」→「揮発素材で匂いを広げる」
    紙片の「匂いの広がるもの」と合うようになった。


■ 3. 灰汁の重複を解いた（案A・採取品を改名）

  data_items.js
    item_044「灰から取った灰汁」→「灰滲みの水」
      categoryId / reactionId（liquid / permeate）はそのまま。
      description と note を書き換え、強アルカリの灰汁ではなく
      「竈跡に雨が滲みて溜まった薄い水」という別物にした。
      note の中で灰汁液に触れ、別物だと分かるようにしてある。

  data_spawns.js
    竈跡の note「竈の灰から漉す」「灰を漉す」→「竈の底に溜まっている」

    どのレシピからも itemId 指名されていない素材なので、
    改名による波及はありません。
    調合用の灰汁は item_076「灰汁液」（木灰＋水質を煮る）のまま。


■ 4. 未採取の素材を棚に出すようにした

  main.js
    採取素材 71種が最初から棚に並ぶ。未採取のうちは薄字で、
    在庫数の代わりに採れるエリアが出る。行を押せば覚え書きが開く。

    未採取のとき出るもの   名前 / 短い説明 / エリア
    採取したあと出るもの   上に加えて 詳しい note / 地形 / 時間帯

    エリアは採取表から地形→エリアで逆引きして重複を潰している。
    四つ以上のエリアで採れるものは「森・草原・川辺 ほか」と丸める
    （AREA_LISTED = 3 で変えられる）。
    満月しばりのものには「満月の夜にかぎる。」が付く。

    まだ作っていない調合品は、これまでどおり伏せたまま。

  style.css
    .item-entry.unheld  未採取の行
    .memo-where ほか    採取地の欄


■ 5. 在庫0でも棚から消えないようにした

  main.js
    visibleItems() の held(id) <= 0 で切る判定を外した。
    一度でも手にしたもの（everHeld）は 0 でも残る。
    .item-entry.depleted が付いて薄くなり、調合台には載らない。

    handleItemClick() の早期 return を直した。
    切らしていても未採取でも、行を押せば覚え書きは開くようになる。

    棚の「◯種」は、並んだ行数ではなく手元にある種類を数えるようにした。
