## 1. コンセプト
「博物学者」や「探検家」の視点で、断片的なヒントから世界の法則を読み解く、謎解き重視の錬金術RPG。グラフィックに頼らず、テキストの情緒とシステムの論理性で没入感を演出する。

## 2. コアシステム
### 探索システム（方眼探索と謎解き）
* [cite_start]**方眼マップ**: 10×10のグリッドから、1回の探索につき10マスを選択。 [cite: 1, 8]
* [cite_start]**時間概念**: 朝・昼・夜で出現素材や確率が変化。 [cite: 8, 9]
* [cite_start]**二段構えの発見**: 初期は「メモ（ヒント）」のみ。発見後に詳細データ（図鑑）が解禁。 [cite: 8, 59, 60]

### 調合システム（4元素ロジック）
[cite_start]調理工程と属性をリンクさせた直感的な調合システム。 [cite: 16]
* [cite_start]**火**: 焼く・炒める（薬効増幅・性質変化） [cite: 10, 18]
* [cite_start]**水**: 煮る・溶かす（成分抽出・希釈・濃縮） [cite: 3, 16]
* [cite_start]**土**: すりつぶす・砕く（物理的分解） [cite: 3, 19]
* [cite_start]**風**: 乾燥させる（保存性向上・水分除去） [cite: 16]
